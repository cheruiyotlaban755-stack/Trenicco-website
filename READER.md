
# Trenic-Co. — Business Website

A modern, clean, and responsive business website built using HTML5 and CSS3.

## About the Project

TrenicCo is a business landing page designed to showcase web design, web development, and digital marketing services.

The website features a simple navigation bar, an attractive hero section, service cards, and a professional footer.

## Features

- Responsive design for desktop, tablet, and mobile devices
- Navigation links to different website sections
- Hero section with call-to-action buttons
- Service cards with hover effects
- About section
- Contact information and footer
- Smooth scrolling

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries

## Project Structure

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Ensure you have an internet connection to load the external hero image.
